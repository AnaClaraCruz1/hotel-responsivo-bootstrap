# Hotel Aurora — Site Responsivo

Projeto acadêmico desenvolvido para a **UC 4 do curso do SENAC**, com o objetivo de criar uma página web responsiva para um hotel utilizando o framework Bootstrap.

## Sobre o projeto

O **Hotel Aurora** é um site demonstrativo de hospedagem, criado a partir do wireframe fornecido na atividade. A interface utiliza uma identidade visual com tons de verde, cores neutras e detalhes suaves para transmitir conforto e hospitalidade.

## Funcionalidades

- Navegação com menu responsivo.
- Seção de apresentação do hotel.
- Destaques dos benefícios da hospedagem.
- Cartões para as suítes Solteiro, Casal e Master.
- Formulário demonstrativo para solicitação de reserva.
- Validação de campos obrigatórios, e-mail e datas.
- Layout adaptável para computadores, tablets e celulares.

> **Importante:** o formulário é apenas demonstrativo. Ele valida os dados no navegador, mas não envia informações para um servidor nem efetua reservas reais.

## Tecnologias utilizadas

- **HTML5** — estrutura semântica do conteúdo.
- **CSS3** — identidade visual e ajustes de estilo.
- **JavaScript** — validação do formulário e interações.
- **Bootstrap 5.3.3** — sistema de grid, componentes e responsividade.
- **Bootstrap Icons** — ícones da interface.

O Bootstrap e as imagens são carregados por CDN/URLs externas; por isso, é necessária conexão com a internet para visualizar todos os recursos.

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador atualizado.
4. Para testar a responsividade, redimensione a janela ou utilize o modo de dispositivos móveis nas ferramentas de desenvolvedor do navegador.

Não é necessário instalar dependências ou executar um servidor local para visualizar a versão demonstrativa.

## Responsividade

A página utiliza as classes de grid do Bootstrap, como `container`, `row`, `col-12`, `col-md-*` e `col-lg-*`, para reorganizar os elementos de acordo com a largura da tela. O menu é recolhido em telas menores, os cartões dos quartos mudam de quantidade por linha e os campos do formulário se ajustam ao espaço disponível.

## Objetivo educacional

Praticar a aplicação de tecnologias front-end e técnicas de responsividade, seguindo o wireframe proposto na atividade da UC 4.
