# Hotel Aurora — Site Responsivo

Projeto acadêmico desenvolvido para a **UC 4 do curso do SENAC**, com o objetivo de criar uma página web responsiva para um hotel utilizando HTML, CSS, JavaScript e Bootstrap 5.

## Sobre o projeto

O **Hotel Aurora** é um site demonstrativo de hospedagem, criado com base no wireframe proposto na atividade. A interface utiliza tons de verde, cores neutras e detalhes suaves para transmitir conforto e hospitalidade.

## Funcionalidades

- Menu de navegação responsivo.
- Seção de apresentação do hotel.
- Destaques dos benefícios da hospedagem.
- Cartões para as suítes Solteiro, Casal e Master.
- Formulário demonstrativo para solicitação de reserva.
- Validação de campos obrigatórios e datas, com validação de formato de e-mail pelo navegador.
- Layout adaptável para computadores, tablets e celulares.

> **Importante:** nesta versão da atividade, o formulário realiza validações no navegador e exibe uma mensagem demonstrativa. Os dados ainda não são enviados a um servidor e nenhuma reserva real é efetuada.

## Tecnologias utilizadas

- **HTML5** — estrutura do conteúdo.
- **CSS3** — estilos personalizados e ajustes responsivos.
- **JavaScript** — validações e interações do formulário.
- **Bootstrap 5.3.3** — grid, componentes e responsividade.
- **Bootstrap Icons** — ícones da interface.

O Bootstrap, os ícones e as imagens são carregados por URLs externas (CDN), portanto é necessária conexão com a internet para visualizar todos os recursos.

## Como executar

1. Clone ou baixe este repositório.
2. Entre na pasta interna `hotel-responsivo-bootstrap/`.
3. Abra o arquivo `index.html` em um navegador atualizado.
4. Para verificar a responsividade, redimensione a janela ou utilize o modo de dispositivos móveis nas ferramentas de desenvolvedor do navegador.

Não é necessário instalar dependências nem executar um servidor local para visualizar esta versão.

## Responsividade

A página utiliza o sistema de grid do Bootstrap para reorganizar o conteúdo conforme a largura da tela. O menu é recolhido em telas menores, os cartões dos quartos se distribuem em colunas responsivas e os campos do formulário se ajustam ao espaço disponível.

## Objetivo educacional

Praticar a construção de uma interface web responsiva a partir de um wireframe, utilizando tecnologias front-end e validações no formulário, conforme os requisitos da atividade da UC 4.
